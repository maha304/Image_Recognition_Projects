# Medical Image Analysis Portfolio

> Exploratory computer-vision work focused on understanding medical imaging datasets and preparing reliable foundations for future predictive modeling.

## Featured Project: Fetal Ultrasound EDA

This project explores fetal ultrasound images and head-circumference metadata as the first stage of a future image-based estimation workflow.

### Questions explored

- What does the ultrasound dataset contain?
- Are the image files correctly matched to the measurement metadata?
- How are head-circumference measurements and pixel spacing distributed?
- What preprocessing decisions will be needed before model development?

## Current Status

**Exploratory analysis and data validation are complete. Model development and clinical validation have not yet been completed.** The repository intentionally reports only the work supported by the current notebook.
